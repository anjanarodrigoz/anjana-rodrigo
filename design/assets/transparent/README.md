# Anjana Rodrigo — Transparent Portfolio Asset Pack

Each asset is a separate high-resolution RGBA PNG with a transparent background.
The files can be freely positioned, layered, scaled, and combined in website or
presentation layouts.

## Mining assets

- `mining/open-pit-mine-diorama.png` — complete open-pit mining environment
- `mining/haul-truck.png` — isolated yellow mining haul truck
- `mining/hydraulic-excavator.png` — isolated tracked excavator
- `mining/processing-plant.png` — isolated mineral-processing plant

## Digital operations assets

- `ui/rugged-field-tablet.png` — mine-operations tablet
- `ui/fleet-dispatch-laptop.png` — fleet-management dashboard
- `ui/mining-cycle-time-phone.png` — mobile cycle-time interface
- `ui/electric-blue-data-network.png` — glowing connection-line overlay

## Avatar assets

- `avatar/anjana-with-laptop.png` — seated cartoon avatar with laptop
- `avatar/anjana-portrait.png` — standing portrait-style cartoon avatar

## Suggested layering

1. Place the mine diorama as the environmental base.
2. Add the truck, excavator, or processing plant as independent foreground pieces.
3. Position the laptop, tablet, and phone above or around the mine.
4. Place the data-network overlay between the physical and digital layers.
5. Add either avatar pose as the main human focal point.

The `sources` directory contains the original green-screen generations used to
produce the transparent PNGs. It is excluded from the distributable ZIP.
