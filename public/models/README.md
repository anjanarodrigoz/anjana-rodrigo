# Character model

Put a rigged character here as `character.glb` and the site uses it automatically in place of the built-in figure.

- Format: binary glTF (`.glb`), ideally under 5 MB.
- Standing upright, feet at the origin, facing +Z.
- If the file contains animations, the first one plays on a loop (an idle or breathing clip works best).

Good sources: a Ready Player Me avatar made from a photo, a Mixamo character with an idle animation, or a model built in Blender.
